Experimental and unstable: partial prerendering. With `createWebApp({ experimental: { ppr: { shellChecks } } })`, a route whose backend half exports `shellLoader` streams a shell shared by every visitor, then each `dynamic` boundary as it settles. The shell loader receives no request, and a shell is shared only for a route that passed the import check for this deployment; any other route renders whole. Hole HTML is checked on the server and inserted without running scripts, every script in the document is allowed by hash, and leaving the page cancels the holes still loading. Every hole loader, on a streamed document, a navigation's data request or a whole render, runs under its own deadline and a per-process admission limit that stops admitting a boundary whose loaders keep running after their abort; a prefetch starts no hole. A client that stops reading is cut off once its unsent bytes pass a per-response or per-process budget. `experimental.ppr.origin` gives `shellLoader` and the shell's `meta` the deployment's public origin, never a visitor's Host; in development a shell with fewer than 200 characters of text warns, since Safari does not paint such a page until its last hole arrives. The React adapter renders a hole's HTML with `renderFragment`.
