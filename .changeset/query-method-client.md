The typed client calls a QUERY route as `$query(body, options?)`, the body positional and checked against the route's schema as for `post()`, so a route segment named `query` stays an ordinary path. `NAMESPACED_KEYS` lists `$query`, and `reservedKeyFor()` reports a segment spelled `$query`, which is reached by calling its parent node. A `$` in a segment passed to a parent-node call is no longer percent-encoded, so that call reaches a static segment written with one. QUERY joins the default retry methods.
