`--shell tauri` scaffolds a site with a Tauri 2 shell: the `src-tauri/` project and transport module `nifra shell tauri` writes, `backend/shell-origins.ts` with the shell origins the server's CORS accepts, and `shell:dev` and `shell:build` scripts. It needs the site template, which it implies.
